Trackers and bot-detection services also fingerprint you at the network layer. No extension or page script can read these, but servers see them on every request.

All collection happens locally. Nothing leaves your browser. The combined ID is a non-cryptographic hash (cyrb53) of the stable attributes and only identifies this browser on this machine for comparison purposes.
